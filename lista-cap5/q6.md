a) #include <stdio.h> (usando < >): Diz para o compilador procurar aquele arquivo nas pastas padrões do sistema/compilador. Usamos para as bibliotecas padrão do C.   #include "areas.h" (usando " "): Diz para o compilador procurar primeiro na mesma pasta onde está o nosso projeto/código-fonte. Usamos para arquivos que nós mesmos criamos.

b) O comando #undef SOMA desfaz a definição da macro. Ou seja, a partir daquela linha, a macro SOMA deixa de existir e se você tentar usar no código vai dar erro.   Escrever #undef SOMA(x,y) está incorreto porque o #undef só precisa receber o nome (identificador) da macro para cancelar ela, não precisa da lista de argumentos.

c) Se não foi definido, vai cair no #else e imprimir a mensagem: Modo normal.   Essa decisão é tomada no momento de pré-processamento, bem antes do programa rodar de verdade.As diretivas (tudo que começa com #) não aparecem no executável final porque elas só servem pra preparar o texto do código. O pré-processador simplesmente avalia o #ifdef e deleta as linhas de código que não passaram na condição. O que sobra pro compilador é só C puro, sem as diretivas.
