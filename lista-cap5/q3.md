a) void exibe_mensagem(char* msg);: Tem parâmetro de entrada (recebe uma string/ponteiro de char), mas não tem valor de retorno (void).   int obter_codigo(void);: Não tem parâmetros de entrada (void), mas tem valor de retorno (devolve um int).   void limpar_tela(void);: Não tem parâmetros de entrada (void) e também não tem valor de retorno (void).

b) Na prática, uma função com retorno serve para calcular ou buscar alguma informação e devolver esse dado para o resto do programa usar (guardar numa variável, colocar num if, etc.). Já um procedimento (void) serve apenas para executar uma tarefa ou ação, sem precisar devolver nenhum dado de volta.
Exemplo para função com retorno: Calcular a média das notas de um aluno (float calcular_media(...)), porque eu preciso pegar esse resultado depois para saber se ele passou ou reprovou.
Exemplo para procedimento (void): Uma função para imprimir o menu principal do sistema na tela (void mostrar_menu()), porque ela só precisa mostrar o texto para o usuário e não precisa devolver nenhum valor para o código.

Como a função limpar_tela foi declarada com o tipo de retorno void, ela literalmente não devolve nenhum dado (retorna "nada"). Por isso, não tem como atribuir o resultado dela a uma variável x, já que não existe nenhum valor vindo da função para ser guardado ali.
