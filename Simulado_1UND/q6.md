A) Porque a variável soma foi declarada dentro do bloco do for (int soma = 0;). Ela só existe dentro daquele escopo (entre as chaves { } do for). Quando o programa chega no printf fora do laço, a variável soma já "deixou de existir" para o compilador.

B) Iterações executadas: i vai de 1 até 7.; 
Impacto do continue: Quando i == 5, o continue faz o programa pular o resto do bloco e ir direto para a próxima repetição (i = 6), sem somar o quadrado do 5.
Impacto do break: Quando i == 8, o break encerra o laço for imediatamente, então as iterações 8, 9 e 10 nem acontecem.

C) 
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0; // declarada fora do escopo do for

    for (i = 1; i <= 10; i++) {
        if (i == 5) continue;
        if (i == 8) break;
        soma += i * i;
    }

    printf("Soma final = %d\n", soma);
    system("PAUSE");

    return 0;
}
