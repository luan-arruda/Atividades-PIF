

Valores Iniciais:
`a = 2`, `b = 4`, `c = 5`, `d = 10`

1. **`a += b + c;`**
   * Avalia a soma à direita: `b + c` $\rightarrow$ `4 + 5 = 9`.
   * Atribuição: `a = a + 9` $\rightarrow$ `2 + 9 = 11`.
   * **Estado:** `a = 11`, `b = 4`, `c = 5`, `d = 10`

2. **`b *= c = d - 2;`**
   * Associatividade da direita para a esquerda:
     1. `c = d - 2` $\rightarrow$ `10 - 2 = 8` (a variável `c` passa a valer **8**).
     2. `b *= c` $\rightarrow$ `b = 4 * 8 = 32`.
   * **Estado:** `a = 11`, `b = 32`, `c = 8`, `d = 10`

3. **`d %= a + 3;`**
   * Avalia a soma à direita: `a + 3` $\rightarrow$ `11 + 3 = 14`.
   * Operação de resto: `d = 10 % 14 = 10`.
   * **Estado:** `a = 11`, `b = 32`, `c = 8`, `d = 10`

4. **`a += b += c += 5;`**
   * Associatividade da direita para a esquerda:
     1. `c += 5` $\rightarrow$ `c = 8 + 5 = 13`.
     2. `b += c` $\rightarrow$ `b = 32 + 13 = 45`.
     3. `a += b` $\rightarrow$ `a = 11 + 45 = 56`.
   * **Estado final:** `a = 56`, `b = 45`, `c = 13`, `d = 10`
