Os três erros de compilação no código são:

Ponto e vírgula na diretiva #include <stdlib.h>;: Diretivas do pré-processador não devem terminar com ponto e vírgula.

Nome da função principal int Main(): O C é case sensitive, então a função precisa ser escrita em minúsculo.

Falta de aspas no printf: A mensagem " A idade do aluno eh: %d anos.. " precisa estar entre aspas duplas. Além disso, o comando cout << endl; pertence ao C++, não existe em C puro (o correto seria usar printf("\n"); ou puts("");).
