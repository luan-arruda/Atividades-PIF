b) ifs independentes: Cada instrução if é testada pelo programa, independentemente de o if anterior ter sido verdadeiro ou falso.   Cadeia else-if: As condições são testadas em ordem até encontrar a primeira verdadeira. Assim que uma condição é atendida, o seu bloco é executado e o programa ignora todas as outras verificações seguintes da estrutura.
c)
#include <stdio.h>

int main() {
    int idade = 25;

    if (idade >= 60) {
        printf("Idoso\n");
    } else if (idade >= 18) {
        printf("Adulto\n");
    } else if (idade >= 12) {
        printf("Jovem\n");
    } else {
        printf("Criança\n");
    }

    return 0;
}
