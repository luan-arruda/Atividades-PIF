a) A mensagem impressa no console será Opção B.   Justificativa: O primeiro if (x > 10) é verdadeiro (pois $15 > 10$). Em seguida, o programa entra no segundo if (y > 10), que é falso (pois $5$ não é maior que $10$). Como o else pertence a este segundo if, ele executa o printf("Opção B\n");.  
b) A regra da Linguagem C diz que um else sempre se associa ao if mais próximo que ainda não tenha um else correspondente, desde que não esteja dentro de outro bloco demarcado por chaves {}. Por isso, apesar da indentação enganosa no código, o else pertence ao if (y > 10) e não ao if (x > 10).

#include <stdio.h>

int main() {
    int x = 15, y = 5;

    if (x > 10) {
        if (y > 10) {
            printf("Opção A\n");
        }
    } else {
        printf("Opção B\n");
    }

    return 0;
}
