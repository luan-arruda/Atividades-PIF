a) Saída exata impressa pelo printf:
a = 0, b = 5, c = 8
b) O conceito de avaliação de curto-circuito funciona da seguinte forma:   Operador E (&&): Se a primeira condição for falsa, o resultado final já será falso. Portanto, o compilador não avalia as expressões seguintes.Operador OU (||): Se a primeira condição for verdadeira, o resultado final já será verdadeiro. Por isso, o compilador ignora e não avalia as expressões seguintes.
c) Se a condição fosse if (a == 0 || ++b > 5):   Como a é igual a 0, a primeira expressão a == 0 é verdadeira.Por conta do curto-circuito no operador ||, a segunda parte (++b > 5) não é avaliada, logo b continua valendo 5.Como a condição do if foi verdadeira, ele executa c += 10, logo c passa a ser $10 + 10 = 20$.Valores finais: b = 5 e c = 20.
