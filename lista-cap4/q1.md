a) Quando escrevemos if (x = 0), estamos fazendo uma atribuição e não uma comparação.   O valor de x passa a ser 0.   O resultado da expressão dentro do if passa a ser 0. Como em C o valor 0 equivale a falso, o bloco dentro do if nunca é executado (o programa ignora esse bloco e vai para o else, se houver).   Já em if (x == 0), estamos apenas comparando se x é igual a 0, sem alterar o valor armazenado na variável x.
b) Em Linguagem C, não existe um tipo booleano nativo clássico nas versões antigas (como o ANSI C):   O valor 0 (zero) representa o falso.   Qualquer valor diferente de 0 (positivo ou negativo, inteiro ou real) é avaliado como verdadeiro.
c) Na instrução if (x = -5):Primeiro ocorre a atribuição: a variável x recebe o valor -5.   O resultado da expressão dentro da condição passa a ser -5.   Como -5 é um valor diferente de zero, a Linguagem C avalia essa condição como verdadeira.   Conclusão: O bloco de código associado ao if será executado.
