b) Comportamento do Trecho B:O laço fica lendo caractere por caractere via getch() até o usuário digitar a letra 'X'.   A operação 'ch' + 1 pega o valor ASCII do caractere digitado e imprime o caractere seguinte na tabela ASCII (por exemplo, se digitar 'A', imprime 'B').   Os parênteses em (ch = getch()) são obrigatórios por causa da precedência de operadores: o operador de comparação != tem precedência maior que o de atribuição =. Sem os parênteses, o C faria getch() != 'X' primeiro (retornando 0 ou 1) e depois atribuiria esse resultado boleano para a variável ch. 

c) Como interromper o Trecho C:
Podemos usar o comando break dentro de uma condição if no corpo do laço, ou uma chamada de função como return / exit() para encerrar a função ou programa de forma controlada.
