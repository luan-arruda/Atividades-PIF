a) Dá erro de compilação porque a variável soma foi declarada dentro do bloco do for (int soma = 0;). Quando o código tenta usar soma no printf fora do laço, essa variável já não existe mais no escopo do programa.

b) A variável soma é reinicializada com 0 a cada iteração do for, ou seja, em vez de acumular o resultado de 1 a 9, ela ia ficar guardando só o valor do último quadrado calculado. Além disso, quando o laço termina, a memória que guardava o valor de soma é liberada automaticamente por estar restrita ao escopo do for.

c)
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0; // declarada fora do escopo do for

    for (i = 1; i < 10; i++) {
        soma += i * i;
    }

    printf("Soma final = %d\n", soma);
    system("PAUSE");

    return 0;
}
