a) O laço executará exatamente 5 iterações. Ele roda para as combinações $(i=0, j=10)$, $(i=1, j=9)$, $(i=2, j=8)$, $(i=3, j=7)$ e $(i=4, j=6)$. Quando chega em $i=5$ e $j=5$, a condição $i < j$ dá falsa ($5 < 5$ é falso) e o laço encerra.

b) Saída exata do printf:
i = 0, j = 10 | soma = 10
i = 1, j = 9 | soma = 10
i = 2, j = 8 | soma = 10
i = 3, j = 7 | soma = 10
i = 4, j = 6 | soma = 10

c)
#include <stdio.h>

int main() {
    int i = 0, j = 10;

    while (i < j) {
        printf("i = %d, j = %d | soma = %d\n", i, j, i + j);
        i++;
        j--;
    }

    return 0;
}
