b) Como o incremento x++ é pós-fixado, o C primeiro compara o valor atual de x com 5 e depois soma +1 em x (independente de a condição dar verdadeira ou falsa):

1ª checagem: avalia 0 < 5 (Verdadeiro). x vira 1.
2ª checagem: avalia 1 < 5 (Verdadeiro). x vira 2.
3ª checagem: avalia 2 < 5 (Verdadeiro). x vira 3.
4ª checagem: avalia 3 < 5 (Verdadeiro). x vira 4.
5ª checagem: avalia 4 < 5 (Verdadeiro). x vira 5.
6ª checagem: avalia 5 < 5 (Falso). O laço encerra, mas o incremento pós-fixado ainda roda, e x vira 6.

c)
#include <stdio.h>

int main() {
    int x = 0;

    while (x < 5) {
        x++;
    }
    x++; // incremento final referente a checagem que deu falsa

    printf("Valor final de x = %d\n", x);

    return 0;
}
